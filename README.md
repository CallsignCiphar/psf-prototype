# Pakistan Strategic Forum, web front end

Next.js (App Router) + Tailwind CSS v4 + Lucide icons. Front end only: it connects to the existing backend, which is unchanged.

- `npm install`, then `npm run dev` and open http://localhost:3000
- `/prototype` lists every screen and its states.
- Design tokens live in `app/globals.css` (`@theme`): PSF green, white and light green, rounded corners, soft shadows.
- Sample content lives in `lib/data.ts` and stands in for API responses.
