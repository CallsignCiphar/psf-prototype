# PSF Website and Portal Prototype

Static, clickable prototype of the Pakistan Strategic Forum public website, contributor and approver portal, admin dashboard and modal library. Desktop only. All names, figures and dates are sample content; the PSF roundel stands in for the logo.

- `index.html` lists every screen.
- The "All screens" button (bottom left) returns to the index. Screens with state variants show a switcher beside it.

## Deploy

Plain static HTML, no build step. On Vercel: Add New, Project, import this repo, Framework preset "Other", leave build and output settings empty, Deploy. `vercel.json` turns on clean URLs.
